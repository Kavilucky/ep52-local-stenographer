# Локальный стенографист: протоколы встреч без облака

Комплект к ролику канала «ByteAutomate» — https://t.me/ByteAutomate_AI.

Контур из faster-whisper (расшифровка записи) и локальной модели Ollama (протокол решений) в docker-compose. Работает на вашем компьютере, интернет при работе не нужен, ключей и паролей в комплекте нет.

## Быстрый запуск

Пошаговая инструкция и памятка по бэкапу 3-2-1 — в `ИНСТРУКЦИЯ.txt`. Коротко:

1. Скопируйте `.env.example` в `.env` и при необходимости поправьте значения.
2. Положите запись встречи в `./audio`.
3. Один раз заранее скачайте образы и модели (см. комментарий в начале `docker-compose.yml`).
4. `docker compose up` — в `./out` появятся `transcript.txt` и `protocol.md`.

## Состав

- `docker-compose.yml` — три сервиса, healthcheck, тома под модели, сеть `internal: true`
- `worker.py` — оркестратор (выгружает Whisper из VRAM перед вызовом Ollama)
- `system_prompt.txt` — промпт секретаря-референта
- `backup_321.sh`, `backup_321.bat` — бэкап 3-2-1 с проверкой SHA256
- `.env.example` — пример переменных окружения

## Важно

- Нужно своё железо; 4 ГБ VRAM — рабочий минимум, будет медленно.
- Качество протокола зависит от записи: шум и перебивания портят и таймкоды, и итог.
- Оригиналы записей не удаляйте, пока бэкап 3-2-1 не подтверждён.
- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных.
